# MYSX-256/512 v0.1-draft: exact linear model and cryptanalysis data

Generated by `python3 mysx_linear_model.py report` (all numbers below are produced by that script; `python3 mysx_linear_model.py selftest` machine-checks the model against the real cipher).

## 1. The model in one page

Bit `b` of a word is the bit with weight `2^b`; `bit i of rotl(x,k) = x_{i-k}`. A mask `u` selects the parity `u . s`. Trail masks `m_0 .. m_R` (`m_r` on `s[r]`) satisfy, for a fixed key,

```
m_{r+1} . s[r+1]  =  m_r . s[r]  (+)  m_r . rk[r]      up to the approximations of F
```

**Only non-linear element:** `F(x) = (rotl(x,1) & rotl(x,8)) ^ rotl(x,2)`. For masks `b` (output) and `g` (input):

```
b.F(x) (+) g.x = Q_b(x) (+) l.x ,   l = rotr(b,2) (+) g ,   Q_b(x) = XOR_j b_{j+1} x_j x_{j-7}
```

`Q_b` is a quadratic form whose graph `G_b` is a subgraph of the 32-cycle `j -- j-7` (edge `(j, j-7)` present iff `b_{j+1} = 1`; one single cycle because gcd(7,32)=1). With `A_b` the GF(2) adjacency matrix of `G_b`:

* `corr(b,g) != 0`  iff  `l = A_b y` for some `y` (so exactly `2^rank(A_b) = 4^h` valid `g`);
* then `corr(b,g) = (-1)^{Q_b(y)} * c0(b)` and `|corr| = 2^-h`, `h = rank(A_b)/2`;
* `h(b)` = maximum matching = minimum vertex cover of `G_b` (a forest; König), except `b = 0xFFFFFFFF` (full cycle): rank 30, `h = 15`;
* a run of `e` consecutive active edges costs `floor((e+1)/2)`; Parseval holds (`sum_g corr^2 = 1`).

**Round, forward direction** (input mask `m` on `s[r]`, cells `p = 0..3` with `L = word p`, `R = word p+4`):

```
b_p = m[p]                       only words 0..3 of the input mask decide the cost
g_p in valid(b_p)                free choice among 4^h(b_p) values, all with |corr| = 2^-h(b_p)
n[p+4] = m[p] ;  n[p] = m[p+4] (+) g_p
m_next = lin_fwd(n, r)           byte transposition, then rotl by (r mod 31)+1: masks move like data
weight w_r = sum_p h(m[p]) ;  sign = prod_p sign_p * (-1)^{m . rk[r]}
```

Backward direction (ciphertext side): `n = lin_bwd(m_next, r)`; then `b_p = n[p+4]`, `m[p] = b_p`, `m[p+4] = n[p] (+) g_p`. Final whitening adds the constant sign `(-1)^{m_R . rkFinal}`.

**Correlation of a trail** = `prod_r 2^-w_r * (-1)^{sum_r m_r.rk[r]} * prod sign_p`. **Linear hull** (exact, fixed key) = sum over all trails with the same `(m_0, m_R)`; `propagate()` computes it by correlation-vector propagation (pruned by weight). **ELP** (key independent, assumes independent round keys, which is not true for this deterministic schedule) = `sum corr_T^2`: `propagate(..., elp=True)`.

## 3. LAT of F: cost data

* Single-bit `b`: `h = [1]` for all 32 positions (corr `+-1/2`, 4 valid `g`).
* Two-bit `b` (496 masks), histogram of `h`: `{2: 464, 1: 32}` (the 32 pairs with bit distance 7 are adjacent edges and cost only 1).

## 7. What this does and does not establish

**Established (machine-checked by `selftest`):** the exact LAT of F (valid set, magnitude, sign); the exact per-round mask rule; key-sign tracking; existence of key-independent-magnitude (|corr| = 1) single-bit relations over up to 9 consecutive rounds; the model reproduces the real cipher within sampling error.

**Not established:** a lower bound on the best trail weight over 128 rounds (beam values are upper bounds from single-bit starts only); an exact hull (pruned); the cost of a key-recovery attack; behaviour of multi-bit starts at larger R. The weight-0 windows are a property of 5-9 round windows of a 128-round cipher, not an attack on the full cipher.

**Exact MILP/SAT encoding (for a certified bound):** variables = the 8 mask words per round; per cell, weight = minimum vertex cover of `G_b` (cover variables `S_v`, constraints `S_j + S_{j-7} >= b_{j+1}`, objective `sum S_v`; exact for `b != 0xFFFFFFFF`), and the validity constraint `g = rotr(b,2) (+) A_b y` (equivalently `l` orthogonal to `ker A_b`: per odd path component the XOR of `l` over its even-position vertices is 0, and `l_v = 0` on vertices touched by no active edge). Sign tracking is not needed for magnitudes.

## 8. API cheat sheet

```python
from mysx_linear_model import *
lat_row(b).h                  # cost h(b) of output mask b
valid_gammas(b)               # all (g, sign) with corr = sign*2^-h
corr_Z(b, g) / 2**32          # exact signed corr of b.F(x)^g.x
round_options(m, r)           # all (next_mask, sign) of round r from mask m
lin_fwd(n, r), lin_bwd(m, r)  # linear layer on masks
rks = key_schedule(key)[0]    # real round keys
propagate(m0, R, rks=rks, T=20, r0=0)   # signed hull, fixed key
propagate(m0, R, elp=True, T=20)        # ELP, key independent
empirical_corr(m0, mR, rks, R, N=1<<22, r0=0)
beam_trails(R, low_hw_masks(1), beam=1200, hexp=2, r0=12)
```
